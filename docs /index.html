🤖 Wiki Oficial de CodeCord

CodeCord es un bot multifuncional de Discord de nueva generación escrito en Node.js + discord.js v14 que incluye un completo panel web administrativo SPA (Express) para gestionar el 100% de la configuración de tus servidores sin tocar archivos JSON ni memorizar sintaxis compleja.

🚀 Despliegue Rápido

Instalación en menos de 5 minutos con variables de entorno preparadas y despliegue global de comandos.

🛡️ Anti-Raid V2

12 módulos de protección continua con ventana deslizante de 60s y aislamiento automático de intrusos.

🖥️ Panel Web Gamer

Interfaz Glassmorphism estilo ProBot/Dyno/Nekotina con autenticación OAuth2 de Discord.

🚀 Inicio Rápido

git clone https://github.com/aitor1234567899/CodeCord.git
cd CodeCord
npm install
cp .env.example .env      # Rellena BOT_TOKEN, CLIENT_ID, CLIENT_SECRET
npm run deploy            # Registra los 57 slash commands
npm start                 # Arranca el bot + panel web

Panel Web predeterminado disponible en: http://localhost:22550

✨ Novedades Destacadas v10.50

  • UI/UX Interfaz Web de Alta Gama: Nueva estética futurista gamer con Glassmorphism, buscador desplegable Ctrl+K y sidebar de 5 categorías.
  • Seguridad Notificaciones MD en /warn: Envío automático de mensaje privado estructurado con detalles de la sanción al usuario advertido.
  • Panel Cargar y Editar Mensajes: Importa cualquier mensaje existente enviando la ID o URL directa para modificarlo en vivo.
  • Datos Aislamiento Total por Servidor: Cada guild almacena sus configuraciones y logs de sanciones en su propio directorio aislado dentro de servidores/.

⚙️ Instalación y Puesta en Marcha

1. Requisitos del Sistema

Requisito Versión Recomendada Notas
Node.js 18.x LTS o superior (Desarrollado en v24) Esencial para soporte de discord.js v14
npm v9.x o superior Gestor de paquetes predeterminado
Discord Application Bot Privilegiado Activar PRESENCE, MEMBERS y MESSAGE CONTENT Intents

2. Registro de Slash Commands

CodeCord dispone de un script centralizado para publicar todos los comandos globales y por servidor:

npm run deploy

ℹ️ La propagación global de comandos por parte de Discord puede tardar hasta 1 hora en completarse. Para pruebas inmediatas, define GUILD_ID en tu archivo .env.

3. Control de Instancia Única

El bot implementa un mecanismo de bloqueo basado en archivo bot.lock que almacena el PID del proceso activo. Esto evita conflictos de socket o respuestas duplicadas en Discord si se intenta ejecutar más de un bot simultáneamente.

🔧 Variables de Entorno (.env)

Copia el archivo .env.example a .env y configura tus credenciales:

Variable Requerido Descripción
BOT_TOKEN Sí Token secreto del bot obtenido del Discord Developer Portal.
CLIENT_ID Sí ID de la aplicación de Discord.
CLIENT_SECRET OAuth2 Secret de aplicación necesario para login en panel web y verificación.
PORT Opcional Puerto del panel administrativo (Por defecto: 22550).
PANEL_URL OAuth2 URL pública raíz del panel (ej: http://localhost:22550).

Modos de Autenticación del Panel

En el archivo WEB/admin-panel.js puedes configurar la constante LOGIN:

  • LOGIN = true (Recomendado): Exige inicio de sesión con Discord. Restringe el acceso únicamente a usuarios con permiso de Administrador o Gestionar Servidor.
  • LOGIN = false: Modo libre para pruebas en entorno local sin conexión OAuth2.

🖥️ Panel Web Administrativo

El panel web integrado en CodeCord está desarrollado como una Single Page Application (SPA) responsive de alta calidad. Permite la administración total del servidor mediante peticiones HTTP asíncronas hacia la API interna en Express.

Secciones Principales

📊 Dashboard Hero

Visualiza en vivo el consumo, tiempo encendido, recuento de servidores, canales y actividad reciente.

✉️ Emisor de Mensajes & Webhooks

Envía o edita anuncios formateados como el Bot o con la identidad visual del Servidor.

🎛️ Modulo Anti-Raid V2

Ajusta tolerancias numéricas para creación de canales, spam de roles o menciones masivas.

🎟️ Centro de Tickets

Gestiona tickets abiertos, atiende usuarios vía web y consulta transcripciones HTML archivadas.

🧩 Sistemas Internos de CodeCord

🛡️ Módulo Anti-Raid V2

El sistema Anti-Raid utiliza algoritmos de ventana deslizante de tiempo (60 segundos) para monitorear eventos agresivos en la API de Discord:

  • Vigilancia sobre creación/eliminación masiva de canales y roles.
  • Protección contra bots maliciosos no autorizados.
  • Acción de castigo automática configurable: KICK, BAN o AISLAMIENTO DE ROLES.
  • Lista blanca de administradores exentos por servidor.

🎫 Sistema de Tickets con Modales

Ofrece paneles personalizables con hasta 5 botones independientes. Cada botón despliega un formulario modal donde el usuario debe detallar su motivo antes de crear el canal privado de atención.

👋 Generador de Tarjetas de Bienvenida

Utiliza la librería de procesamiento gráfico Jimp para renderizar en tiempo real tarjetas personalizadas con el avatar, nombre y contador de miembros al unirse un nuevo usuario.

🔌 Referencia API REST del Panel

Todos los endpoints requieren autenticación de sesión activa cuando LOGIN = true y validan los permisos de administrador en el servidor correspondiente (:guildId).

Método Ruta Endpoint Descripción
GET/api/statusMétricas de salud, memoria RAM y latencia del bot.
GET/api/guildsLista de servidores administrables por el usuario actual.
POST/api/guilds/:guildId/sendPublica mensajes de texto o embeds como el bot.
PUT/api/guilds/:guildId/message/:channelId/:messageIdEdita un mensaje publicado previamente por el bot.
GET/api/guilds/:guildId/membersObtiene la lista paginada de miembros (cursor por snowflake).

🏗️ Arquitectura y Estructura del Código

Estructura modular orientada a eventos e independización de controladores:

CodeCord/
├── index.js                  # Punto de entrada principal
├── src/
│   ├── index.js              # Inicialización de Discord Client e Intents
│   ├── server.js             # Lanzador del servidor Express para el panel web
│   ├── handlers/             # Autocargadores de comandos y eventos
│   ├── commands/             # Slash commands (usuario / administradores)
│   ├── events/               # Escuchadores de eventos de DiscordJS
│   └── systems/              # Lógica de negocio (AntiRaid, Tickets, Voz...)
├── WEB/
│   ├── admin-panel.js        # Backend API Express (~3.300 líneas)
│   └── admin.html            # Interfaz SPA del Panel Web
└── servidores/               # Persistencia de datos aislada por servidor

💾 Persistencia de Datos

CodeCord emplea un esquema estructurado en archivos JSON aislados por servidor alojados en el directorio servidores/:

servidores/
└── _/
    ├── configuracion/
    │   ├── moderation.json     # Filters, censura y AutoMod
    │   ├── logs.json           # Canales y colores de eventos
    │   └── verification.json   # Modos y roles de verificación
    ├── sanciones/
    │   └── sanciones_.txt
    └── verified-users.json     # Registros de miembros verificados

🩺 Solución de Problemas Frecuentes

Error: Used disallowed intents

Ocurre cuando no se han activado las opciones privilegiadas en el portal de desarrolladores. Dirígete a Discord Developer Portal → Tu Bot → Pestaña Bot y activa los 3 Privileged Gateway Intents.

Error: invalid_client (401) en OAuth2

Asegúrate de que la variable CLIENT_SECRET en tu archivo .env coincide exactamente con el secret de OAuth2 de la aplicación y que no contiene comillas ni espacios extra.

🤝 Guía de Contribución

¡Las contribuciones son bienvenidas! Sigue estos pasos para añadir nuevos comandos o módulos:

  1. Haz un fork del repositorio oficial en GitHub.
  2. Crea un nuevo archivo en src/commands/usuario/ o src/commands/administradores/.
  3. Exporta un módulo que contenga la estructura { name, description, execute }.
  4. Ejecuta npm run deploy para probar tu nuevo comando en Discord.
  5. Envía un Pull Request detallando los cambios introducidos.
